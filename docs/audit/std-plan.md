# برنامهٔ اولویت‌بندی std — فاز ۲

## ۱. انجام‌شده — برنامهٔ پیشنهادی، بدون اجرا

مبنای ترتیب، M1=`hello` و M2=`imports` در درخواست کاربر است؛ این‌ها معیار آینده‌اند، نه نتیجهٔ پورت. وضعیت توابع و ارجاع‌های منبع در std-readiness.md:11 ثبت شده‌اند. Rust std به خودی خود ABI مورد نیاز CPython C را فراهم نمی‌کند؛ build بومی فعلی probeهای C شکست دارد و guestها UNKNOWN هستند (probes/results/results.csv:4؛ std-source-review.log:5). بنابراین اصلاح std و تکمیل C runtime باید با acceptance جداگانه پیش بروند.

اولویت صفر، موفقیت‌های ظاهری و خطاهای پنهان است. `flush=Ok(())` را خودکار خطا فرض نمی‌کنیم: write مستقیم است و fsync جداگانه صریحاً unsupported است (tools/native-std/overlay/stdio/sunlightos.rs:26؛ tools/native-std/overlay/fs/sunlightos.rs:237). setters محلی FileTimes نیز نهایتاً به set_times ناموفق می‌رسند و نسبت به موفقیت C ABI اولویت پایین‌تری دارند (tools/native-std/overlay/fs/sunlightos.rs:79؛ tools/native-std/overlay/fs/sunlightos.rs:267).

تمام آزمون‌های زیر **پیشنهادی و اجرا‌نشده** هستند. برای هر ردیف، host فقط منطق/ABI با backend تزریق‌شده را می‌سنجد و هیچ syscall بومی را روی Linux اجرا نمی‌کند. فرمان پایهٔ پیشنهادی host پس از تأیید فاز ۳:

```sh
CARGO_TARGET_DIR=docs/audit/host-target cargo test -p sunlight-libc --lib --target x86_64-unknown-linux-gnu <test_filter> -- --nocapture
```

وجود seam و قابل‌ساخت‌بودن هر test تا زمان پیاده‌سازی UNKNOWN است. برای compile-only overlay، پس از مجوز جداگانهٔ نوشتن خارج docs/audit می‌توان `tools/check_native_std.sh` را بررسی و فقط بخش compile مناسب را انتخاب کرد؛ فعلاً این اسکریپت اجرا نمی‌شود. تغییر فایل stage به‌جای overlay ممنوعیت فنی این طرح است: منبع اصلی انتخاب overlay در tools/native-std/prepare.py:65 مشخص است.

## ۲. انجام‌نشده / مسدود

هیچ موردی پیاده‌سازی یا آزمایش نشده است. تکمیل Native CPython علاوه بر این جدول به sysroot C، startup و ABI کامل نیاز دارد؛ شکست native build در probes/results/results.csv:4 ثبت است. هیچ فرمان build ISO، تغییر دیسک یا اتصال VM در این برنامه اجرا نشده است. آیتم‌های بزرگ پس از بازبینی قابل شکستن به اقلام کوچک‌ترند؛ تصویب کل طرح مجوز اجرای همزمان چند آیتم نیست.
