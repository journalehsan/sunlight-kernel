### 🖼 Description

**SunlightOS Nightly Icons** is a modern, unified icon set designed specifically to complement the **SunlightOS** operating system (Nightly channel).
The design draws inspiration from modern commercial operating systems — without relying on any proprietary or commercial assets — resulting in a clean, neutral, and professional aesthetic that aligns perfectly with the SunlightOS desktop environment.
It aims to deliver a sleek, visually consistent, and vibrant desktop experience for SunlightOS users, while remaining fully compatible with Arch Linux and other GTK/Qt-based desktop environments.

The set includes a comprehensive collection of application icons, system icons, and file type (mimetype) icons, carefully optimized to provide a seamless and beautiful interface across the SunlightOS ecosystem.
