# Melody Mina media integration

Melody Mina is a presentation client of `sunlight-media`. The application owns
exactly one `MelodyMediaController`, and that adapter owns exactly one
`MediaPlayer`/active worker for the lifetime of the window. Rendering reads a
copy-only view model; it never holds a backend lock or accesses decoder, PCM,
audiod, or device state.

The backend has no callback/event-queue API in this phase. Melody therefore
reads its bounded atomic snapshot at 30 Hz only while focused and playing,
10 Hz while unfocused/Loading, and 4 Hz while otherwise idle. Media position is
always copied from the backend hardware-consumption clock; the UI timer does
not advance time. Visualization is one replaceable fixed-size latest frame,
not an event queue.

Selecting a playlist entry or choosing a file opens and starts it. The bundled
sample loads paused at startup. Previous and Next wrap through the playlist;
Repeat restarts the current track at end of stream. A second click during an
in-progress load of the same path keeps the existing request. If the worker is
handling another command, the controller retains the latest requested track or
seek and retries it on refresh. An accepted Open synchronously publishes
`Loading` and increments the source generation. Controller refreshes reject
snapshots from the previous source. The timeline previews a drag and waits for
the worker's seek acknowledgement before resuming the hardware position clock.

On window close, the app is dropped after the event loop. Controller drop then
drops `MediaPlayer`, which requests worker shutdown, flushes application audio,
and releases decoder/source storage.

## The Living Sunlight sample

Two bundled MP3 examples, `002-Zamfir-EinsamerHirte.mp3` and
`014-SecretGarden-SongFromASecretGarden.mp3`, are also seeded under both users'
Music directories. They appear in the normal Melody Mina playlist alongside
the Ogg and WAV examples, with their ID3 titles and artists, and can be used to test play, pause, seek, and track
transitions. Each file is decoded to PCM by `sunlight-media`.

`The Living Sunlight.wav` is seeded in both `/home/user/Music` and `/root/Music`,
so Melody Mina lists it alongside other music on first launch. It is an
18-second, 48 kHz stereo PCM preview generated by `tools/living_sunlight.rs`.
The standalone Rust synth uses the Eb-D-D G-minor motif, ADSR voices, FM,
filtered noise, and staged CPU/memory/entropy values. The bundled WAV is a
fixed render; the synth's atomic controls are available for future live input.

Regenerate the asset on a host with:

```sh
rustc --edition=2021 -O tools/living_sunlight.rs -o /tmp/living-sunlight
/tmp/living-sunlight assets/sounds/the-living-sunlight-48k.wav
```
